# ppm-viewer
1. in gui-src directory, run 'make' command
2. Executable file is gui-src/glut_main
3. 'J' displays first Julia Set image
4. 'j' displays second Julia Set image
5. 'M' displays first Mandelbrot image
6. 'm' displays second Mandelbrot image
7. 'C' displays first Complex Fractal image
8. 'c' displays second Complex Fractal image
9. 'T' displays color table
10. 'r' randomly changes the first color if in color table
11. 'R' randomly changes the second color if in color tables
12. 't' exits color table
13. 'b' enters Mandelbrot mode
14. 'n' enters Julia mode
15. 'F' enters Complex Fractal mode
16. '.' increases color table size
17. ',' decreases color table size
18. 'z' zooms in
19. 'Z' zooms out
20. arrow keys move around
21. left mouse creates Julia set from coordinates of mouse click, if you were in Mandelbrot before
22. '+' or '=' increases escape count
23. '-' or '_' decreases escape count
